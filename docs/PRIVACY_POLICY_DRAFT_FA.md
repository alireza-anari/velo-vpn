# پیش‌نویس حریم خصوصی Velo

> این متن محصولی/فنی است و پیش از انتشار عمومی باید متناسب با کشور و ساختار حقوقی کسب‌وکار بازبینی شود.

Velo برای ارائه VPN فقط داده‌های لازم برای عملکرد، پرداخت، پاداش و امنیت سرویس را نگهداری می‌کند.

## داده‌های قابل نگهداری
- شناسه نصب ناشناس و وضعیت دستگاه؛
- ایمیل فقط پس از ساخت حساب توسط کاربر؛
- وضعیت Premium، قلب‌ها، ماموریت‌ها و دعوت‌ها؛
- زمان کلی اتصال، سرور انتخاب‌شده و مقدار کلی ارسال/دریافت برای گزارش مصرف و عملیات؛
- تصویر رسید پرداخت دستی تا مدت لازم برای بررسی و امور مالی؛
- داده‌های فنی لازم برای جلوگیری از تقلب و خطاهای عملیاتی.

## داده‌هایی که Velo برای پروفایل‌سازی ذخیره نمی‌کند
- تاریخچه وب‌سایت‌های بازدیدشده؛
- محتوای بسته‌های شبکه، پیام‌ها یا فایل‌ها؛
- تاریخچه DNS یا فهرست مقصدهای اینترنتی کاربران.

## تبلیغات
نسخه رایگان از تبلیغات جایزه‌ای استفاده می‌کند. SDK ارائه‌دهنده تبلیغات ممکن است طبق سیاست خودش داده فنی دستگاه یا شناسه تبلیغاتی را پردازش کند. این بخش باید هنگام انتخاب نسخه نهایی SDK و شبکه‌های فعال دوباره بررسی شود.

## حساب و پرداخت
شماره موبایل دریافت نمی‌شود. حساب اختیاری با ایمیل ساخته می‌شود. رسیدهای پرداخت خصوصی هستند و فقط ادمین مجاز باید به آن‌ها دسترسی داشته باشد.

## امنیت
توکن‌های محلی اپ با Android Keystore محافظت می‌شوند؛ پنل ادمین از session امن استفاده می‌کند؛ secrets نباید در APK یا repository عمومی قرار گیرند.

## تماس
آدرس تماس نهایی پیش از انتشار جایگزین شود.
