# راهنمای ساده ادمین Velo — نسخه Premium-first

این راهنما برای ادمینی نوشته شده که دانش برنامه‌نویسی زیادی ندارد.

## 1) فعال‌کردن اشتراک یک کاربر

1. وارد پنل ادمین Velo شوید.
2. در بخش «فعال‌سازی اشتراک»، ایمیل کاربر را وارد کنید.
3. مدت ۱۵ روز، ۱ ماه، ۳ ماه یا ۶ ماه را انتخاب کنید.
4. روی «فعال‌سازی» بزنید.
5. کاربر در اپ روی «بروزرسانی وضعیت اشتراک» می‌زند و بلافاصله Premium می‌شود.

اگر ایمیل هنوز در Velo حساب نداشته باشد، پنل آن را ایجاد می‌کند. وقتی کاربر بعداً با همان ایمیل وارد شود، همان اشتراک را می‌بیند.

## 2) پرداخت کارت‌به‌کارت

پرداخت‌های جدید در «پرداخت‌های در انتظار» دیده می‌شوند. رسید را باز کنید؛ اگر مبلغ صحیح بود «تأیید» را بزنید. مدت اشتراک بر اساس پلن انتخابی کاربر خودکار اضافه می‌شود.

## 3) محدودیت یک دستگاه همزمان

یک حساب Premium می‌تواند روی چند گوشی نصب و Login شود، اما فقط یک Session همزمان دارد. اگر کاربر روی دستگاه دوم Connect کند، اپ از او می‌پرسد آیا اتصال دستگاه قبلی قطع شود یا نه.

## 4) اضافه‌کردن VPS جدید بدون Build اپ

اپ هیچ IP مربوط به VPN Nodeها را داخل APK نگه نمی‌دارد. فقط API مرکزی ثابت است. سرورها از Backend انتخاب می‌شوند؛ بنابراین اضافه یا خاموش‌کردن VPS نیاز به APK جدید ندارد.

برای VPS جدید Ubuntu 24.04، یک CIDR تکراری‌نباشد انتخاب کنید. مثال:

- Node 1: 10.77.1.0/24
- Node 2: 10.77.2.0/24
- Node 3: 10.77.3.0/24

روی VPS جدید این دستور را با اطلاعات واقعی اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/alireza-anari/velo-vpn/main/infra/production/provision-vpn-node.sh -o /tmp/velo-node.sh
sudo bash /tmp/velo-node.sh \
  --name DE-01 \
  --country DE \
  --city Frankfurt \
  --public-ip VPS_PUBLIC_IP \
  --central-api-ip CENTRAL_API_PUBLIC_IP \
  --cidr 10.77.2.0/24 \
  --max-sessions 200
```

در پایان اسکریپت چند مقدار چاپ می‌کند: Public Key، Client CIDR، Agent URL و Agent Token. آن‌ها را در بخش «افزودن VPS» پنل ادمین وارد کنید و «ثبت سرور» را بزنید.

بعد از ثبت:
1. روی Health بزنید.
2. اگر سالم بود، سرور آماده دریافت کاربر است.
3. اپ کاربران به‌صورت خودکار از ظرفیت سرورها استفاده می‌کند.

## 5) نظارت روزانه

در صفحه اول پنل این موارد را نگاه کنید:
- تعداد اشتراک فعال
- تعداد اتصال فعال
- پرداخت‌های در انتظار
- تعداد سرورهای فعال
- درصد ظرفیت هر سرور
- Health هر سرور

وقتی یک Node به حدود 70٪ ظرفیت تنظیم‌شده رسید، برای خرید/افزودن Node جدید برنامه‌ریزی کنید.

## 6) اگر سروری مشکل داشت

1. در پنل روی Health بزنید.
2. اگر unhealthy بود، آن Node را «خاموش» کنید.
3. روی Reconcile بزنید.
4. کاربران در اتصال بعدی به Node سالم هدایت می‌شوند.
5. بعد از رفع مشکل، دوباره Node را روشن و Health را بررسی کنید.

## 7) کارهایی که ادمین نباید انجام دهد

- Private Key WireGuard را برای کسی ارسال نکند.
- Agent Token را در چت عمومی یا اسکرین‌شات منتشر نکند.
- دیتابیس PostgreSQL را مستقیماً ویرایش نکند.
- پورت 8787 Node Agent را برای همه اینترنت باز نکند؛ فقط IP سرور API مرکزی اجازه داشته باشد.
- برای اضافه‌کردن VPS جدید APK را تغییر ندهد.

## 8) معماری ساده

```
Android App
    |
    v
Central Velo API + Admin
    |
    +---- VPN Node 1
    +---- VPN Node 2
    +---- VPN Node 3
    +---- ...
```

Control Plane مرکزی ثابت می‌ماند. VPSهای VPN قابل اضافه/حذف هستند.
